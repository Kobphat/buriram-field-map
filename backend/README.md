# ระบบหลังบ้านแบบสอบถาม (Google Sheets + Apps Script)

ข้อมูลทั้งหมดอยู่ใน Google Sheet ของผู้วิจัยเอง GitHub เก็บแค่หน้าเว็บ

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | รับคำตอบจากเว็บ ตรวจรหัส บันทึกลงชีต และให้ข้อมูลกับหน้าหลังบ้าน |
| `Logic.gs` | กติการหัสผู้ตอบ การกันรหัสซ้ำ และการติดธงคำตอบที่น่าจะซ้ำ |
| `Lgu.gs` | รหัส อปท. 40 แห่ง และเป้าโควตาราย อปท. |
| `Admin.html` | หน้าหลังบ้าน |

## ติดตั้ง (ครั้งเดียว)

1. สร้าง Google Sheet ใหม่ในบัญชีที่จะเป็นเจ้าของข้อมูล แล้วเปิด **ส่วนขยาย → Apps Script**
2. สร้างไฟล์สคริปต์ `Code`, `Logic`, `Lgu` และไฟล์ HTML ชื่อ `Admin` แล้ววางเนื้อหาจากไฟล์ในโฟลเดอร์นี้
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** อนุญาตสิทธิ์ ระบบจะสร้างชีต คำตอบ · คู่ผู้สมัคร · เบอร์ติดต่อ · บันทึกระบบ
4. **การตั้งค่าโปรเจ็กต์ → พร็อพเพอร์ตี้ของสคริปต์**
   - `ADMINS` อีเมล Google ที่เข้าหลังบ้านได้ คั่นด้วยจุลภาค
   - `ACCEPT` ปล่อยเป็น `0` จนกว่า EC อนุมัติ (ระหว่างนี้รับเฉพาะข้อมูลทดสอบ)
   - `DELETE_BY` วันที่ต้องลบเบอร์โทร เช่น `2570-06-30`
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** ครั้งที่ 1 สำหรับ **เก็บข้อมูล**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - คัดลอก URL ไปใส่ใน `survey/index.html` ที่ `endpoint`
6. ทำให้ใช้งานได้อีกครั้ง สำหรับ **หลังบ้าน**
   - เรียกใช้ในฐานะ: **ผู้ใช้ที่เข้าถึงเว็บแอป** · ผู้มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google**
   - URL นี้คือลิงก์หลังบ้าน แชร์ Google Sheet ให้อีเมลใน `ADMINS` ด้วย (ผู้แก้ไข) เพราะหน้าหลังบ้านอ่านชีตด้วยสิทธิ์ของผู้ที่เข้าใช้

## โหมดของหน้าแบบสอบถาม (`window.SURVEY_CONFIG` ใน `survey/index.html`)

| ค่า | ผล |
|---|---|
| `{ live: false }` | โหมดตัวอย่าง ไม่ส่งข้อมูล (ค่าปัจจุบัน) |
| `{ live: true, test: true, endpoint: "URL เก็บข้อมูล" }` | ทดสอบระบบ บันทึกจริงแต่ติดค่า test = 1 ลบทิ้งได้จากหลังบ้าน |
| `{ live: true, endpoint: "URL เก็บข้อมูล" }` | เก็บข้อมูลจริง ใช้หลัง EC อนุมัติและตั้ง `ACCEPT = 1` แล้วเท่านั้น |

## ข้อมูลส่วนบุคคล
- เบอร์โทรเก็บเฉพาะผู้ที่ตอบข้อ 75 ว่ายินดี อยู่ในชีตแยก เชื่อมกับคำตอบด้วยรหัสผู้ตอบเท่านั้น
- การเปิดดูรายชื่อเบอร์ถูกบันทึกในชีต “บันทึกระบบ”
- เมื่อสัมภาษณ์รอบ 2 เสร็จ ลบเบอร์ทั้งหมดจากแท็บ “ตั้งค่าและทดสอบ” ในหลังบ้าน
